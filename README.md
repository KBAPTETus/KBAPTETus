## 🚀 Флагманский проект

### 🏆 [Astra-Club-1C — Автоматизация компьютерного клуба](https://github.com/KBAPTETus/Astra-Club-1C)
Тиражируемая конфигурация на платформе 1С:Предприятие 8.3 для автоматизации аренды игровых ПК и розничного бара:
* **Новая методика проведения:** списание и контроль отрицательных остатков через виртуальные таблицы в транзакции.
* **Клиент-серверная оптимизация:** управляемые формы «Такси», перенос вычислений на клиент, директивы `&НаСервереБезКонтекста`.
* **Управленческая аналитика:** гибкие отчеты на СКД (баланс остатков бара, выручка по категориям зон и тарифам).
* Исходный код выгружен в модульном формате под Git, снабжен дистрибутивом `.cf` и демо-базой `.dt`.

## 🛠 Технологический стек

* **Платформа 1С:Предприятие 8.3:** встроенный язык BSL, управляемые формы (Такси), язык запросов 1С, система компоновки данных (СКД), управляемый режим блокировок, стандарты разработки фирмы «1С».
* **Системная разработка:** C++20, STL, ООП, алгоритмы и структуры данных (деревья, графы, хеш-таблицы).
* **СУБД и данные:** 1С (файловая база), основы PostgreSQL, SQL.
* **Инструменты:** Git, GitHub, Linux (Ubuntu), TeXstudio (LaTeX).
